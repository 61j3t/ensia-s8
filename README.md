## Per-chapter notes layout

Each `0X_chapterX_topic.md` file contains:

1. **Bird's eye view** — 5-10 bullet quick-scan summary
2. **Detailed notes** — section-by-section comprehensive coverage
3. **Key terms** — glossary
4. **Exam targets** — likely written-exam questions
5. **Pitfalls** — common confusions and traps
