# Chapter 5 — Monte Carlo Methods

## Bird's eye view

- **Monte Carlo (MC)** = learn value functions and optimal policies by **averaging sample returns** from episodes — no model of `𝒫` or `𝓡` needed, only **experience**.
- Unlike DP, MC does **not assume complete knowledge** of the environment. The model, if any, need only **generate sample transitions**, not the full distribution.
- Defined here only for **episodic tasks**: returns are well-defined only when episodes terminate.
- Two prediction variants: **first-visit MC** (average returns after the *first* time `s` appears in each episode) and **every-visit MC** (average returns after *every* visit). Both converge to `vπ(s)`.
- Without a model, prefer estimating **action values** `qπ(s, a)` — picking a greedy action from `v` needs `𝒫` and `𝓡`, but from `q` it doesn't.
- Action-value MC needs to **maintain exploration**: pairs that are never visited never get evaluated. Two fixes: **exploring starts (ES)** or **ε-soft / stochastic** behaviour.
- Control follows **GPI**: alternate MC policy *evaluation* (`Q → qπ`) with greedy *improvement* (`π → greedy(Q)`).
- **On-policy** = evaluate/improve the policy you act with (uses ε-greedy). **Off-policy** = act with a **behavior** policy `b`, learn a different **target** policy `π`. More general, but higher variance and slower.
- Off-policy MC requires the **coverage assumption** `π(a|s) > 0 ⇒ b(a|s) > 0` and reweights returns by the **importance-sampling ratio** `ρ_{t:T-1} = ∏ π(Aₖ|Sₖ)/b(Aₖ|Sₖ)`.
- Two estimators: **ordinary IS** (unbiased, possibly infinite variance) vs **weighted IS** (biased but with bounded variance). Both can be implemented **incrementally**.

## 1. Introduction — what MC means in RL

### 1.1. The term "Monte Carlo"

- Used broadly for **any estimation method that relies on repeated random sampling**.
- In RL, MC is a **learning method** based on estimating value functions and discovering optimal policies from **experience** — sample sequences of `(states, actions, rewards)` from actual or simulated interaction.

### 1.2. What MC needs (and doesn't need)

| Requirement | DP | **MC** |
|---|---|---|
| Complete model `𝒫, 𝓡` | needed | **not needed** |
| Sample generator only | not enough | **sufficient** |
| Episodes | not required | **required** (defined only for episodic tasks) |
| Bootstrapping (use other estimates) | yes | **no** — uses actual returns |

> In surprisingly many cases it is **easy to sample** experience from the desired distribution, but **infeasible** to write it down in **explicit form**. MC exploits exactly this gap.

### 1.3. Plan of the chapter (mirrors DP)

1. **Prediction**: estimate `vπ` or `qπ` for a given `π`.
2. **Policy improvement**: greedy step over `Q`.
3. **Control via GPI**: alternate the two until both converge.

The value functions and policies still **interact to attain optimality** in the same GPI sense as DP — only the evaluation step has changed (sample averages instead of full backups).

## 2. Monte Carlo Prediction

### 2.1. Goal

Estimate `vπ(s)` from a set of episodes generated by following `π` that pass through `s`.

```math
v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s], \qquad G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots + \gamma^{T-t-1} R_T
```

### 2.2. Visits, first-visit vs every-visit

- A **visit** to `s` = an occurrence of `s` in an episode.
- **First-visit MC**: average the returns following only the **first** visit to `s` in each episode.
- **Every-visit MC**: average the returns following **every** visit to `s` (the same episode can contribute multiple returns).
- **Both converge** to `vπ(s)` as the number of (first) visits to `s` → ∞.

| | First-visit MC | Every-visit MC |
|---|---|---|
| Per episode, contributions to `s` | at most 1 | one per occurrence |
| Independence of returns | yes | no (returns within an episode share data) |
| Convergence | quadratic in `n` for variance | also converges, different constants |
| Most theoretically studied | **yes** | extends more naturally to function approximation |

### 2.3. Computing returns efficiently (backwards)

For a 5-step episode with rewards `R₁..R₅` and `γ = 0.5`, compute returns **backwards** using `Gₜ = R_{t+1} + γ G_{t+1}` so each return costs O(1) instead of O(T-t):

```math
G_5 = 0,\quad G_4 = R_5 + \gamma G_5,\quad G_3 = R_4 + \gamma G_4,\quad \ldots,\quad G_0 = R_1 + \gamma G_1
```

### 2.4. First-visit MC algorithm

```
First-visit MC prediction, for estimating V ≈ vπ

Input: a policy π to be evaluated
Initialize:
    V(s) ∈ ℝ, arbitrarily, for all s ∈ 𝓢
    Returns(s) ← an empty list, for all s ∈ 𝓢

Loop forever (for each episode):
    Generate an episode following π: S₀, A₀, R₁, S₁, A₁, R₂, …, S_{T-1}, A_{T-1}, R_T
    G ← 0
    Loop for each step of episode, t = T-1, T-2, …, 0:
        G ← γG + R_{t+1}
        Unless S_t appears in S₀, S₁, …, S_{t-1}:
            Append G to Returns(S_t)
            V(S_t) ← average(Returns(S_t))
```

### 2.5. Every-visit MC (variant)

Same loop but drop the "unless `S_t` already appeared" check — append `G` to `Returns(S_t)` at **every** step.

```
Every-visit MC prediction, for estimating V ≈ vπ
…
    Loop for each step of episode, t = T-1, T-2, …, 0:
        G ← γG + R_{t+1}
        Append G to Returns(S_t)
        V(S_t) ← average(Returns(S_t))
```

## 3. MC Estimation of Action Values

### 3.1. Why action values

- If a **model is not available**, state values alone are not enough: choosing greedily from `v` requires `𝒫(s, a, s')` and `𝓡(s, a)` to look one step ahead.
- With **action values** `q(s, a)`, the greedy action is simply `argmaxₐ Q(s, a)` — no model needed.
- Primary goal of MC: **estimate `q*`**.

### 3.2. Definition

```math
q_\pi(s, a) = \mathbb{E}_\pi[G_t \mid S_t = s, A_t = a]
```

- **First-visit MC** for `q`: average returns following the **first** time in each episode that `s` was visited *and* `a` was selected there.
- **Every-visit MC** for `q`: average returns following **all** visits to the pair `(s, a)`.

### 3.3. The exploration problem

- Many `(s, a)` pairs may **never be visited** under a deterministic `π`. If `π` is deterministic, only one action is ever taken from each state.
- General problem: **maintaining exploration**.

Two standard remedies:

| Remedy | Idea | Realistic? |
|---|---|---|
| **Exploring starts (ES)** | every `(s, a)` pair has nonzero probability of being selected as the **episode's start** | useful in simulation, **cannot be relied upon** when learning from actual interaction |
| **Stochastic policies** | use a policy with `π(a\|s) > 0` for all `s, a` (e.g., ε-soft) | works in real interaction |

ES guarantees that all state–action pairs are visited an infinite number of times in the limit of an infinite number of episodes.

## 4. Monte Carlo Control

### 4.1. GPI with MC

In **GPI** we maintain both an approximate policy `π` and an approximate value function `Q`:
- **Evaluation**: `Q ⇝ qπ`.
- **Improvement**: `π ⇝ greedy(Q)`.

The two changes **work against each other** (each creates a moving target for the other), but together both `π` and `Q` approach optimality:

```math
\pi_0 \xrightarrow{E} q_{\pi_0} \xrightarrow{I} \pi_1 \xrightarrow{E} q_{\pi_1} \xrightarrow{I} \pi_2 \cdots \xrightarrow{I} \pi_* \xrightarrow{E} q_* \xrightarrow{I} \pi_*
```

where `→ᴱ` denotes a policy evaluation and `→ᴵ` a policy improvement.

### 4.2. Monte Carlo ES (Exploring Starts)

```
Monte Carlo ES (Exploring Starts), for estimating π ≈ π*

Initialize:
    π(s) ∈ 𝒜(s) (arbitrarily), for all s ∈ 𝓢
    Q(s, a) ∈ ℝ (arbitrarily), for all s ∈ 𝓢, a ∈ 𝒜(s)
    Returns(s, a) ← empty list, for all s ∈ 𝓢, a ∈ 𝒜(s)

Loop forever (for each episode):
    Choose S₀ ∈ 𝓢, A₀ ∈ 𝒜(S₀) randomly such that all pairs have probability > 0
    Generate an episode from S₀, A₀, following π: S₀, A₀, R₁, …, S_{T-1}, A_{T-1}, R_T
    G ← 0
    Loop for each step of episode, t = T-1, T-2, …, 0:
        G ← γG + R_{t+1}
        Unless the pair S_t, A_t appears in S₀, A₀, S₁, A₁, …, S_{t-1}, A_{t-1}:
            Append G to Returns(S_t, A_t)
            Q(S_t, A_t) ← average(Returns(S_t, A_t))
            π(S_t) ← argmaxₐ Q(S_t, a)
```

Notes:
- Improvement is **interleaved at the visit level**: as soon as `Q(S_t, A_t)` is updated, `π(S_t)` is greedified.
- `ES` makes the algorithm theoretically clean but unrealistic outside simulation.

## 5. On-policy vs Off-policy

### 5.1. Two routes to "all actions infinitely often"

The only general way to ensure that **all actions are selected infinitely often** is for the agent to **continue to select them**. Two ways to arrange this:

| | **On-policy** | **Off-policy** |
|---|---|---|
| What is improved | the policy used to make decisions | a **different** policy from the one used to generate data |
| Policy must be soft | yes (e.g., ε-greedy) | only the **behavior** policy `b` must be soft |
| Target policy can be deterministic | no (it must explore) | **yes** (greedy/deterministic target is allowed) |
| Simplicity | **simpler**, considered first | more concepts and notation |
| Variance | lower | **higher** |
| Convergence speed | faster | **slower** |
| Generality | special case of off-policy | strictly more general |

- **On-policy control** uses a policy that is **generally soft**: `π(a|s) > 0` for all `s, a`, but gradually shifted closer to a deterministic optimal policy.
- **Off-policy learning** is also seen by some as **key to learning multi-step predictive models** of the world's dynamics, and can learn from data generated by a **non-learning controller** or a **human expert**.

### 5.2. The learning-control dilemma

All learning control methods face a dilemma: they seek to learn action values conditional on subsequent **optimal** behaviour, but they need to **behave non-optimally** in order to explore all actions. The on-policy compromise: learn `qπ` for a **near-optimal** policy that still explores. The off-policy solution: use **two policies** — a **target policy** `π` being learned, and a **behavior policy** `b` that generates the data.

## 6. ε-soft Policies

### 6.1. Definition

A policy is **ε-soft** if:

```math
\pi(a \mid s) \geq \frac{\varepsilon}{|\mathcal{A}(s)|} \quad \text{for all } s, a, \text{ for some } \varepsilon > 0
```

### 6.2. ε-greedy

The on-policy method we present uses **ε-greedy** policies:

- With **probability 1 − ε**: choose the action with maximal estimated action value (the **greedy** action).
- With **probability ε**: select an action **at random** (uniform over `𝒜(s)`).

Resulting probabilities:

```math
\pi(a \mid s) = \begin{cases}
1 - \varepsilon + \dfrac{\varepsilon}{|\mathcal{A}(s)|} & \text{if } a = a^* = \arg\max_{a'} Q(s, a') \\[1.2ex]
\dfrac{\varepsilon}{|\mathcal{A}(s)|} & \text{otherwise}
\end{cases}
```

- Every **nongreedy** action gets the **minimum** probability `ε/|𝒜(s)|`.
- The **greedy** action gets `1 − ε + ε/|𝒜(s)|`.
- ε-greedy policies are examples of ε-soft policies, and **among ε-soft policies, ε-greedy is in some sense closest to greedy**.

### 6.3. On-policy first-visit MC control (ε-soft)

```
On-policy first-visit MC control (for ε-soft policies), estimates π ≈ π*

Algorithm parameter: small ε > 0
Initialize:
    π ← an arbitrary ε-soft policy
    Q(s, a) ∈ ℝ (arbitrarily), for all s ∈ 𝓢, a ∈ 𝒜(s)
    Returns(s, a) ← empty list, for all s ∈ 𝓢, a ∈ 𝒜(s)

Repeat forever (for each episode):
    Generate an episode following π: S₀, A₀, R₁, …, S_{T-1}, A_{T-1}, R_T
    G ← 0
    Loop for each step of episode, t = T-1, T-2, …, 0:
        G ← γG + R_{t+1}
        Unless the pair S_t, A_t appears in S₀, A₀, S₁, A₁, …, S_{t-1}, A_{t-1}:
            Append G to Returns(S_t, A_t)
            Q(S_t, A_t) ← average(Returns(S_t, A_t))
            A* ← argmaxₐ Q(S_t, a)           (ties broken arbitrarily)
            For all a ∈ 𝒜(S_t):
                π(a | S_t) ← { 1 - ε + ε/|𝒜(S_t)|   if a = A*
                             { ε/|𝒜(S_t)|             if a ≠ A*
```

The policy improvement step **rebuilds the full ε-soft distribution** around the new greedy action — not just `π(S_t) ← argmax`.

## 7. Off-policy Prediction via Importance Sampling

### 7.1. Setting

Estimate `vπ` (or `qπ`) but **only have episodes generated by `b`**, where `b ≠ π`. Both policies are **fixed**.

- `π` = **target policy** (what we want to evaluate; may be deterministic).
- `b` = **behavior policy** (what generates data; must be stochastic in the relevant places).

### 7.2. Coverage assumption

```math
\pi(a \mid s) > 0 \implies b(a \mid s) > 0 \qquad \forall s, a
```

Every action that `π` might take must be possible under `b`. Hence `b` must be **stochastic** wherever it differs from `π`. The target `π` may itself be **deterministic** — a case of particular interest in **control**.

### 7.3. Trajectory probability under any policy

Given starting state `S_t`, the probability of the subsequent trajectory `A_t, S_{t+1}, A_{t+1}, …, S_T` under any policy `π` is:

```math
\Pr\{A_t, S_{t+1}, A_{t+1}, \ldots, S_T \mid S_t, A_{t:T-1} \sim \pi\}
= \prod_{k=t}^{T-1} \pi(A_k \mid S_k)\, p(S_{k+1} \mid S_k, A_k)
```

where `p` is the state-transition probability.

### 7.4. The importance-sampling ratio

The **importance-sampling ratio** is the ratio of trajectory probabilities under `π` and `b`:

```math
\rho_{t:T-1} \doteq \frac{\prod_{k=t}^{T-1} \pi(A_k \mid S_k)\, p(S_{k+1} \mid S_k, A_k)}{\prod_{k=t}^{T-1} b(A_k \mid S_k)\, p(S_{k+1} \mid S_k, A_k)} = \prod_{k=t}^{T-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)}
```

> **Crucial**: the transition probabilities `p(S_{k+1} | S_k, A_k)` **cancel out**. The ratio depends **only on the two policies and the action sequence**, not on the MDP dynamics. This is what makes off-policy MC model-free.

### 7.5. The reweighted expectation

```math
\mathbb{E}[\rho_{t:T-1}\, G_t \mid S_t = s] = v_\pi(s)
```

i.e. multiplying the return obtained under `b` by `ρ_{t:T-1}` corrects its expected value to be the value under `π`.

### 7.6. Two estimators

Let `𝒯(s)` = set of time steps in which state `s` is visited (every-visit MC) or only first-visit times (first-visit MC); `T(t)` = first termination time after `t`.

| Estimator | Formula | Bias | Variance |
|---|---|---|---|
| **Ordinary importance sampling** | `V(s) = ( Σ_{t ∈ 𝒯(s)} ρ_{t:T(t)-1} G_t ) / \|𝒯(s)\|` | **unbiased** | **can be unbounded** (even infinite) |
| **Weighted importance sampling** | `V(s) = ( Σ_{t ∈ 𝒯(s)} ρ_{t:T(t)-1} G_t ) / ( Σ_{t ∈ 𝒯(s)} ρ_{t:T(t)-1} )` | **biased** (bias → 0) | **bounded** (often much lower in practice) |

```math
V(s) \doteq \frac{\sum_{t \in \mathcal{T}(s)} \rho_{t:T(t)-1}\, G_t}{|\mathcal{T}(s)|} \qquad \text{(ordinary)}
```

```math
V(s) \doteq \frac{\sum_{t \in \mathcal{T}(s)} \rho_{t:T(t)-1}\, G_t}{\sum_{t \in \mathcal{T}(s)} \rho_{t:T(t)-1}} \qquad \text{(weighted)}
```

If the denominator of the weighted form is zero, the estimate is defined as zero.

## 8. Incremental MC implementations

### 8.1. Incremental ordinary average (every-visit)

For on-policy MC, since `V(s)` is a simple average of returns, the classical incremental mean applies. The algorithm needs no list, only a running count and running mean.

### 8.2. Off-policy every-visit prediction (uses `W = ρ` running)

```
Off-policy every-visit prediction, for estimating V ≈ vπ

Input: a policy π to be evaluated
Initialize:
    V(s) ∈ ℝ, arbitrarily, for all s ∈ 𝓢
    Returns(s) ← an empty list, for all s ∈ 𝓢

Loop forever (for each episode):
    Generate an episode following b: S₀, A₀, R₁, …, S_{T-1}, A_{T-1}, R_T
    G ← 0;  W ← 1
    Loop for each step of episode, t = T-1, T-2, …, 0:
        G ← γ W G + R_{t+1}
        Append G to Returns(S_t)
        V(S_t) ← average(Returns(S_t))
        W ← W · π(A_t | S_t) / b(A_t | S_t)
```

### 8.3. Incremental weighted importance sampling

Given a sequence of returns `G₁, G₂, …, G_{n-1}` all starting in the same state, with corresponding **random weights** `Wᵢ = ρ_{tᵢ:T(tᵢ)-1}`, the weighted IS estimate is:

```math
V_n \doteq \frac{\sum_{k=1}^{n-1} W_k G_k}{\sum_{k=1}^{n-1} W_k}, \qquad n \geq 2
```

Let `Cₙ` = **cumulative sum of weights**, and let `V₁` be arbitrary. Then the **incremental update** is:

```math
V_{n+1} \doteq V_n + \frac{W_n}{C_n}\bigl[G_n - V_n\bigr], \qquad n \geq 1
```

```math
C_{n+1} \doteq C_n + W_{n+1}, \qquad C_0 \doteq 0
```

Form: a **stochastic-approximation update** with step size `Wₙ / Cₙ` and "target" `Gₙ`.

### 8.4. Off-policy MC prediction (incremental, weighted IS, action values)

```
Off-policy MC prediction (policy evaluation) for estimating Q ≈ qπ

Input: an arbitrary target policy π
Initialize, for all s ∈ 𝓢, a ∈ 𝒜(s):
    Q(s, a) ∈ ℝ (arbitrarily)
    C(s, a) ← 0

Loop forever (for each episode):
    b ← any policy with coverage of π
    Generate an episode following b: S₀, A₀, R₁, …, S_{T-1}, A_{T-1}, R_T
    G ← 0
    W ← 1
    Loop for each step of episode, t = T-1, T-2, …, 0, while W ≠ 0:
        G ← γG + R_{t+1}
        C(S_t, A_t) ← C(S_t, A_t) + W
        Q(S_t, A_t) ← Q(S_t, A_t) + (W / C(S_t, A_t)) · [G - Q(S_t, A_t)]
        W ← W · π(A_t | S_t) / b(A_t | S_t)
```

The inner loop exits early **as soon as `W = 0`** — once any factor `π(A_t|S_t) = 0`, the trajectory carries no information about `π` from that point further back.

## 9. Off-policy Monte Carlo Control

### 9.1. The advantage

- The **target policy** `π` may be **deterministic** (e.g., greedy w.r.t. `Q`), while the **behavior policy** `b` keeps sampling **all** possible actions.
- We follow `b` while **learning about and improving** `π`.
- Required: `b` has nonzero probability of selecting all actions that `π` might select (**coverage**).
- To explore everything, we require the **behavior policy be soft** — selects all actions in all states with nonzero probability.

### 9.2. Off-policy MC control algorithm

```
Off-policy MC control, for estimating π ≈ π*

Initialize, for all s ∈ 𝓢, a ∈ 𝒜(s):
    Q(s, a) ∈ ℝ (arbitrarily)
    C(s, a) ← 0
    π(s) ← argmaxₐ Q(s, a)         (with ties broken consistently)

Loop forever (for each episode):
    b ← any soft policy
    Generate an episode using b: S₀, A₀, R₁, …, S_{T-1}, A_{T-1}, R_T
    G ← 0
    W ← 1
    Loop for each step of episode, t = T-1, T-2, …, 0:
        G ← γG + R_{t+1}
        C(S_t, A_t) ← C(S_t, A_t) + W
        Q(S_t, A_t) ← Q(S_t, A_t) + (W / C(S_t, A_t)) · [G - Q(S_t, A_t)]
        π(S_t) ← argmaxₐ Q(S_t, a)     (with ties broken consistently)
        If A_t ≠ π(S_t) then exit inner Loop (proceed to next episode)
        W ← W · 1 / b(A_t | S_t)
```

Key points:
- The target `π` is **greedy** → `π(a|s) ∈ {0, 1}`.
- When the behaviour action `A_t = π(S_t)`, `π(A_t|S_t) = 1`, so `W` updates simply as `W ← W / b(A_t|S_t)`.
- The **first time** (going backwards from `T`) that `A_t ≠ π(S_t)`, `π(A_t|S_t) = 0` → all earlier (`t` smaller) updates would be multiplied by 0 → **exit the inner loop**.
- Consequence: only the **tail** of the episode after the last non-greedy action contributes — off-policy MC control **learns only from the tails of episodes**, which is why it can be slow.

## Key terms (glossary)

- **Monte Carlo (MC)** — estimation by averaging samples; in RL, averaging sample returns from episodes.
- **Episodic task** — task that terminates; MC requires this so `Gₜ` is well-defined.
- **Visit** — an occurrence of state `s` (or pair `(s, a)`) in an episode.
- **First-visit MC** — average returns following the first visit per episode.
- **Every-visit MC** — average returns following every visit.
- **GPI** — generalized policy iteration: alternate evaluation and improvement.
- **Exploring Starts (ES)** — start each episode in a `(s, a)` drawn so every pair has positive probability.
- **ε-soft policy** — `π(a|s) ≥ ε/|𝒜(s)|` for all `s, a`.
- **ε-greedy policy** — picks greedy action w.p. `1 - ε`, uniform random w.p. `ε`; a particular ε-soft policy.
- **Maintaining exploration** — guaranteeing all `(s, a)` pairs are visited infinitely often.
- **On-policy** — improve the policy used to generate data.
- **Off-policy** — improve a target policy different from the behavior policy.
- **Target policy `π`** — the policy being learned (often greedy).
- **Behavior policy `b`** — the policy used to generate data (must be soft).
- **Coverage** — `π(a|s) > 0 ⇒ b(a|s) > 0`.
- **Importance-sampling ratio `ρ_{t:T-1}`** — `∏ π(Aₖ|Sₖ)/b(Aₖ|Sₖ)`; corrects expected return from `b` to `π`.
- **Ordinary importance sampling** — divide weighted sum of returns by **count** of returns; unbiased, possibly unbounded variance.
- **Weighted importance sampling** — divide weighted sum of returns by **sum of weights**; biased, bounded variance.
- **Cumulative weight `Cₙ`** — running sum of `Wₖ` used in the incremental weighted IS update.

### Pitfalls

- **MC is for episodic tasks only** in this chapter — applying it to non-terminating tasks gives undefined returns.
- **MC does not bootstrap** — never confuse an MC update with a TD update; MC uses the actual `G_t`, not an estimate of it.
- **First-visit returns within an episode are i.i.d.; every-visit returns are not** — this matters when discussing convergence rates or variance.
- **Picking greedy from `v` needs a model** — that is the entire reason MC switches to estimating `q`.
- **Exploring Starts is unrealistic** for real interaction — never claim it as a "general" solution.
- **ε-greedy is improved by rebuilding the full ε-soft distribution**, not by setting `π(S_t) ← argmax Q(S_t, ·)` deterministically (that would break the soft property).
- **In the IS ratio, the transition probabilities `p(s'|s, a)` cancel** — students often write them in the final formula by mistake.
- **Ordinary IS is unbiased but can have infinite variance**; **weighted IS is biased but has bounded variance** — don't swap these properties.
- **Off-policy MC control only learns from the tail of each episode** after the last non-greedy action — explains its slow convergence.
- **`W = 0` exit**: once any `π(A_t|S_t) = 0`, no earlier step in that episode contributes — exit the inner loop immediately to avoid wasted work.
- **Coverage is asymmetric**: it requires `b` to cover `π`, not the other way around.
